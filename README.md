# Shrishail Kerur — Portfolio

Static portfolio site. No build step.

## Run locally
Open `index.html` in a browser, or serve the folder:

```
npx serve .
```

## Deploy on GitHub Pages
1. Push this folder's contents to a repository (e.g. `shrishail-portfolio`).
2. Repo **Settings → Pages** → Source: *Deploy from a branch* → `main` / root.
3. Site goes live at `https://<username>.github.io/<repo>/`.

## Structure
- `index.html` — page markup and styles
- `main.js` — scroll reveals, beam animation, parallax, timecode
- `assets/` — photos and show reel
